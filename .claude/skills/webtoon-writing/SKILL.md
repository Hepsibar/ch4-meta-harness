# 웹툰 각본 작성

웹툰은 짧은 분량(보통 한 화 60~90컷)을 손가락으로 내리며 읽는 매체다. 소설의 설명 밀도나 영화의 긴 호흡을 그대로 가져오면 템포가 늘어진다. 한 화 안에서 궁금증을 걸고(훅) 끝에서 다음 화를 보게(클리프행어) 만드는 것이 핵심이다.

## 1. 신규 시리즈일 때: 연재 바이블

`_workspace/01_writer_bible.md`에 다음 구조로 쓴다.

```
# {작품 제목}

## 로그라인
한 문장. "{주인공}이 {목표}를 위해 {갈등}에 맞선다."

## 장르 · 타깃 · 포맷
- 장르 / 보조 장르
- 타깃 독자층
- 연재 분량(화당 대략 컷 수), 전체 구성(단편·시즌제 등)

## 세계관
- 배경(시대·장소·규칙). 이야기에 쓰이는 설정만 적는다. 쓰지 않을 설정은 넣지 않는다.

## 주요 캐릭터(서사 역할)
- 이름 / 역할(주인공·대립자 등) / 욕망 / 결핍 / 비밀 / 관계
- **외형은 적지 않는다.** 시각 설정은 character-designer가 확정한다.

## 연재 방향
- 핵심 질문(독자가 끝까지 궁금해할 것), 대략의 단계별 전개
```

## 2. 에피소드 시나리오

`_workspace/01_writer_scenario.md`에 **장면 단위**로 쓴다. director가 장면을 컷으로 분해하므로 장면 번호를 반드시 매긴다.

```
# {작품} {N}화 — {부제}

## 이번 화 목표
- 이 화가 전진시키는 것(사건·관계·정보) 한두 줄
- 도입 훅 / 마지막 클리프행어 한 줄씩

## 장면 S1 — {장소/시간}
- 상황: 무슨 일이 일어나는가(3~5줄)
- 감정선: 누구의 어떤 감정이 핵심인가
- 대사:
  - 캐릭터A: "..."
  - (내레이션): ...
  - 캐릭터B: "..." (효과음: 쾅)

## 장면 S2 — ...
```

## 3. 웹툰 각본 원칙

- **한 화 = 하나의 감정 포물선.** 작은 질문을 열고 작은 답(또는 더 큰 질문)으로 닫는다.
- **도입 3컷 안에 훅.** 설명으로 시작하지 않는다. 장면·행동·대사로 시작하고 설정은 흘려서 전달한다.
- **마지막은 클리프행어 또는 감정의 정점.** 다음 화를 보게 만드는 질문·반전·여운으로 끝낸다.
- **대사는 짧게.** 말풍선은 작다. 한 말풍선 한두 호흡. 긴 설명은 내레이션이나 여러 컷으로 나눈다.
- **말투로 캐릭터를 구분한다.** 같은 뜻도 인물마다 어휘·종결어미·리듬이 달라야 한다. 바이블의 성격과 일치시킨다.
- **보여 주고 말하지 않는다.** 감정을 "슬펐다"로 쓰지 말고 행동·표정·상황으로 드러낼 수 있게 장면을 짠다(연출은 director가 맡지만, 각본이 그 여지를 줘야 한다).

## 4. 금지

- 바이블과 모순되는 설정 변경을 말없이 하지 않는다. 바꾸려면 바이블을 먼저 고치고 사유를 남긴다.
- 캐릭터 외형·색·의상을 단정하지 않는다. character-designer의 몫이다.
- 한 장면에 사건을 몰아넣지 않는다. 컷으로 못 풀 만큼 밀도가 높으면 장면을 나눈다.
