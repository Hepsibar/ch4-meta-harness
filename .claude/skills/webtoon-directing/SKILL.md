# 웹툰 연출 · 콘티

세로 스크롤 웹툰은 가로 페이지 만화와 읽는 방식이 다르다. 독자는 위에서 아래로 한 방향으로만 내리며, 컷 사이 여백의 길이가 시간·긴장을 만든다. 칸을 좌우로 나누는 전통 만화 문법을 그대로 쓰면 시선이 꼬인다.

## 1. 컷 분해

시나리오의 각 장면(S1, S2 ...)을 컷으로 나눈다. **컷당 핵심 하나**가 원칙이다: 한 동작, 한 감정, 한 정보.

- 대사가 긴 장면은 말풍선 단위로 컷을 나눈다.
- 중요한 순간(반전·감정 정점·클리프행어)은 큰 컷 + 앞뒤 여백으로 강조한다.
- 컷 번호는 `cut_001`부터 순서대로. 이 번호가 이미지 파일명(`cut_001.png`)과 최종 조립 순서가 된다.

## 2. 컷 명세 템플릿

`_workspace/03_director_storyboard.md`에 컷마다 쓴다.

```
### cut_001  (장면 S1)
- 구도/샷: {익스트림 롱샷 / 롱샷 / 미디엄 / 바스트 / 클로즈업 / 익스트림 클로즈업}
- 앵글: {아이레벨 / 하이앵글 / 로우앵글 / 부감 / 앙각}
- 화면 속 인물: {이름}, 위치({좌/중/우}), 동작, 표정
- 배경: {장소, 디테일 수준, 원근}
- 조명/분위기: {예: 창밖 노을 역광, 차가운 형광등}
- 말풍선/텍스트: 
  - {이름}: "대사" (위치: 상단좌)
  - (내레이션): "..." (위치: 하단)
  - 효과음: 쾅 (위치: 중앙)
- 스크롤 메모: {컷 크기(소/중/대), 앞뒤 여백(없음/보통/길게), 전환 의도}
```

## 3. 연출 원칙

- **카메라 완급을 설계한다.** 롱샷으로 상황을 보여 주고, 클로즈업으로 감정을 찍는다. 같은 샷이 연속되면 단조로워진다.
- **시선은 한 방향.** 다음 컷으로 자연스럽게 내려가도록 인물 시선·동작 방향을 아래쪽 흐름에 맞춘다.
- **여백으로 시간을 만든다.** 긴 여백 뒤의 컷은 "한 박자 쉬고"의 효과를 낸다. 반전·정적·충격 직전에 쓴다.
- **클리프행어 컷은 크게, 정보는 적게.** 마지막 컷은 큰 화면 + 강한 표정/구도로 여운을 남긴다.
- **art-director가 그릴 수 있게 구체적으로.** "대화한다"가 아니라 샷·앵글·위치·표정·조명을 지정한다. 모호하면 작화가 제각각 나온다.

## 4. 말풍선 배치

- 읽기 순서는 위→아래. 한 컷에 말풍선이 여럿이면 위에서 아래로 읽히게 배치한다.
- 말풍선이 인물 얼굴·핵심 요소를 가리지 않게 위치를 지정한다(작화 영역 확보).
- 내레이션은 보통 컷 상단 또는 하단 띠, 효과음은 동작 지점 근처.

## 5. 금지
- 한 컷에 여러 사건·대사를 몰아넣지 않는다. 넘치면 컷을 나눈다.
- 좌우로 칸을 분할하는 가로 만화식 레이아웃을 쓰지 않는다. 세로 스크롤은 한 컷 = 한 화면이 기본이다.
- 컷 번호를 비우거나 건너뛰지 않는다. 번호가 이미지·조립과 직접 연결된다.
